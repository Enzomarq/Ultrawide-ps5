PS5 Aspect Ratio Controller
Projeto experimental para investigar a possibilidade de ajustar proporção de tela no PS5 desbloqueado.
Status: experimental, sem modificações no firmware, por enquanto.
Objetivo: testar desenho de padrões na tela e investigar possibilidades de interceptação de renderização.
Aviso: projeto em andamento, pode mudar a qualquer momento.

## Development Roadmap

The project will be developed in stages, starting with basic research and gradually moving toward more advanced graphics modifications.

### Phase 1 — Development Environment
- [ ] Identify available PS5 homebrew development tools.
- [ ] Verify compatibility with PS5 firmware 13.60.
- [ ] Configure the C/C++ development environment.
- [ ] Evaluate etaHEN plugin development capabilities.
- [ ] Identify the available SDKs and their limitations.

### Phase 2 — First Homebrew Application
- [ ] Create a basic PS5 homebrew application.
- [ ] Test application execution on the target firmware.
- [ ] Display basic graphical elements, such as rectangles, lines, and grids.
- [ ] Investigate GPU access and rendering capabilities.

### Phase 3 — Graphics Research
- [ ] Study framebuffer and rendering pipelines.
- [ ] Investigate viewport and aspect ratio handling.
- [ ] Research horizontal and vertical scaling techniques.
- [ ] Evaluate the possibility of intercepting game rendering.

### Phase 4 — Aspect Ratio Controller
- [ ] Develop independent horizontal scaling controls.
- [ ] Develop independent vertical scaling controls.
- [ ] Implement adjustable image positioning.
- [ ] Create an experimental configuration interface.

### Phase 5 — Game Compatibility
- [ ] Investigate compatibility with native PS5 games.
- [ ] Explore possible system-level or game-specific integration.
- [ ] Test initial concepts with Death Stranding 2.
- [ ] Evaluate performance, stability, and graphical limitations.

### Project Safety

All development and testing will initially take place without modifying the PS5 firmware or replacing the existing jailbreak environment.

No system-wide functionality will be considered implemented until it has been successfully tested.

**Current Status:** Research and development environment preparation.
